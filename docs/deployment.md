# Deployment

| Part | Host | Why |
|---|---|---|
| Database | **Neon** (free Postgres 16) | No expiry on the free plan (Render's free Postgres is deleted after 30 days + a 14-day grace period) |
| API | **Render** (free web service, Docker) | Builds `backend/Dockerfile` straight from the repo |
| Frontend | **Vercel** | Static hosting for the Vite build |

Free-tier behaviour to expect: the Render service sleeps after 15 minutes without traffic and takes about a minute to wake on the next request; the Neon database suspends after 5 minutes idle and resumes on the next query. Open the app once before a demo.

## What happens on every deploy

The container runs `python -m scripts.prestart` before starting the API:

1. `alembic upgrade head` applies any new migrations.
2. The admin login is created, or its password reset, from `ADMIN_USERNAME` / `ADMIN_PASSWORD`.
3. Countries and currencies are upserted; 10,000 employees are seeded **only if there are none**, so a redeploy never overwrites data HR has edited.

No shell access is needed (Render's free plan has none).

## Steps

1. **Neon:** create a project (Postgres 16) and copy the **direct** (non-pooled) connection string. Migrations run on startup and the API needs only a few connections, so the pooler adds nothing.
2. **Render:** *New → Blueprint*, select this repository. `render.yaml` defines the service; fill in:
   - `DATABASE_URL`: the Neon connection string (`postgres://` URLs are accepted as-is)
   - `ADMIN_PASSWORD`: a strong password for the HR manager
   - `CORS_ORIGINS`: the Vercel URL from step 3 (update after the first frontend deploy)

   `JWT_SECRET` is generated by Render. The first deploy seeds the database; check `https://<api>.onrender.com/health`.
3. **Vercel:** import the repository with **Root Directory** `frontend` (Vite is detected). Set `VITE_API_URL` to `https://<api>.onrender.com/api/v1` and deploy. `vercel.json` rewrites every path to `index.html` so links like `/employees` work on reload.
4. Set Render's `CORS_ORIGINS` to the Vercel URL if you haven't, and redeploy the API.

## Operations

- **Change the admin password:** update `ADMIN_PASSWORD` on Render and redeploy.
- **Reset demo data:** run `python -m scripts.seed` from `backend/` with `DATABASE_URL` pointing at Neon. It replaces all employees.
- **Exchange rates:** edit `backend/scripts/seed_data/currencies.json` and redeploy; rates are upserted on start without touching employees.
